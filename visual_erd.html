Car Dealership ERD

Visual representation of database design (Challenge 1).

CARS
PK car_id (INT)
VIN (VARCHAR(17)) (NOT NULL, UNIQUE)
manufacturer (VARCHAR(50))
model (VARCHAR(50))
year (INT)
color (VARCHAR(20))
SALESPERSONS
PK salesperson_pk (INT)
staff_id (INT) (NOT NULL, UNIQUE)
name (VARCHAR(100))
store (VARCHAR(100))
CUSTOMERS
PK customer_pk (INT)
customer_id (INT) (NOT NULL, UNIQUE)
name (VARCHAR(100))
phone_number (VARCHAR(20))
email (VARCHAR(100))
address (VARCHAR(255))
city (VARCHAR(50))
state_province (VARCHAR(50))
country (VARCHAR(50))
zip_postal_code (VARCHAR(20))
INVOICES (Transaction)
PK invoice_pk (INT)
invoice_number (INT) (NOT NULL, UNIQUE)
date (DATE) (NOT NULL)
FK car_id (INT)
FK customer_pk (INT)
FK salesperson_pk (INT)

Relationship Key:

  • PK (Green): Primary Key - Uniquely identifies a record.
  • FK (Red): Foreign Key - Links to a Primary Key in another table.
  • All relationships point **to** the **INVOICES** table (One-to-Many or One-to-One).
